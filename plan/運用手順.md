# ホームページ運用手順

最終更新：2026-09-23

- 公開サイト：https://FSakai1997.github.io/fumiyasakai.github.io/
- 編集コンソール：https://FSakai1997.github.io/fumiyasakai.github.io/admin/

---

## 1. 最初に一度だけ：トークンを発行する

編集コンソールは、GitHubのトークンを鍵として使います。ページ自体は誰でも開けますが、**保存できるのはトークンを持つ人だけ**です。

1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
   （直リンク：https://github.com/settings/personal-access-tokens/new ）
2. **Token name**：`homepage-admin` など分かる名前
3. **Expiration**：1年
4. **Repository access**：`Only select repositories` → `fumiyasakai.github.io`
5. **Permissions** → Repository permissions → **Contents** → `Read and write`
   （これ以外の権限は不要です）
6. `Generate token` を押し、表示された `github_pat_…` をコピー

このトークンでできるのは、このリポジトリのファイル書き換えだけです。他のリポジトリやアカウント設定には影響しません。

### コンソールに入る

1. 編集コンソールを開く
2. トークンを貼る
3. **共用PCでなければ**「このPCに記憶する」にチェック → 次回から入力不要
4. 「接続する」

> **共用PCでは絶対にチェックを入れないでください。** チェックを外すと、タブを閉じた時点でトークンが消えます。

---

## 2. ニュースを追加する

1. 「ニュース」タブ → 左上の **`+ 新規`**
2. 日付・タグ・タイトル・本文を入力
3. **右のプレビューで見た目を確認**（公開ページと同じ表示です）
4. 右上の **`保存する`** → 件数の変化を確認して OK
5. **1〜2分後**に公開サイトへ反映されます

新規作成した記事は最初「下書き」になっています。**下書きのままでは公開されません。** 公開するにはフォーム下部の「下書きにする」のチェックを外してください。

### 本文で使えるタグ

| やりたいこと | 書き方 |
|---|---|
| 段落 | `<p>文章</p>` |
| 改行 | `<br>` |
| 斜体（雑誌名） | `<i>Nature</i>` |
| 太字（自分の名前） | `<strong>Sakai, F.</strong>` |
| リンク | `<a href="https://…" target="_blank">表示する文字</a>` |

### 引用ボックス（論文の情報）

「+ 引用を追加」で追加します。本文に書誌情報を入れ、「+ リンクを追加」でDOIなどへのリンクを付けます。1つの記事に複数の引用を入れられます。

### 日付が期間のとき

学会参加など日付が期間になる記事は、「日付の表示（期間のとき）」に `2023.12.11-15` のように入力してください。空欄なら上の日付から自動で作られます。

---

## 3. 画像を入れる

1. 「画像」タブ → **`画像を追加`** → ファイルを選ぶ
2. アップロード後、記事の編集画面で「+ 画像を追加」→「画像を選ぶ」

**5MBまで**です。超える場合は縮小してください。ファイル名は自動で英数字に整えられます。

**配置を2種類から選べます。**

- **本文の左に並べる**：横に画像、その右に文章
- **本文の上に中央寄せ**：画像を大きく中央に置き、下に文章。「幅」に `75%` などを指定

> 画像の削除機能は意図的に作っていません。記事から参照されている画像を消すと、その記事の画像が表示されなくなるためです。不要な画像は放置して構いません。

---

## 4. CVを更新する

1. 「CV」タブ → 左からセクションを選ぶ
2. 項目を編集、`+ 項目を追加`、`↑`/`↓` で並べ替え、`削除`
3. `保存する`

Publications など連番のセクションには日付欄がありません。書誌情報をそのまま入力してください。

**セクション自体の追加・削除はコンソールからはできません。** 章立てを変える必要が出た場合はご相談ください。

---

## 5. 間違えたとき

### まだ保存していない

画面を再読み込みすれば、編集前の状態に戻ります。

### すでに保存してしまった

**すべての保存はGitHubのコミットとして残っているので、必ず元に戻せます。**

1. https://github.com/FSakai1997/fumiyasakai.github.io/commits/main を開く
2. 戻したいコミットをクリック
3. 右上の `...` → **`Revert`** → `Create pull request` → `Merge`
4. 1〜2分後に公開サイトが元に戻ります

### 「別の場所から更新されています」と出た

コンソールを2つのタブで開いている、あるいはGitHub上で直接編集した場合に出ます。**このメッセージが出たときは保存されていません**（上書き事故を防ぐための仕組みです）。

「GitHubの最新内容を読み直す」を押してから、編集をやり直してください。

---

## 6. トークンの期限が切れたら

有効期限が30日を切ると、コンソール上部に警告が出ます。切れた場合は手順1を再度実行し、新しいトークンをコンソールに貼り直してください。

**トークンを無効にしたいとき**（紛失・共用PCで記憶させてしまった等）：
GitHub → Settings → Developer settings → Personal access tokens → 該当トークン → `Delete`

削除した瞬間から、そのトークンでは保存できなくなります。

---

## 7. 仕組みを変更したいとき（デザイン変更など）

ニュースとCV以外を変える場合は、手元のファイルを編集してGitHubへ送ります。

```bash
git add .
git commit -m "変更内容を書く"
git push origin main
```

`git init` と `git remote add` は不要です（一度設定済みです）。

変更前に、壊れていないか確認できます。

```bash
sh tools/check.sh
```

これは、**移行前の記事内容が1文字も失われていないこと**と、**描画が壊れていないこと**を機械的に検査します（58件）。

## 8. ファイルの役割

| 場所 | 役割 |
|---|---|
| `data/news.json` | ニュース記事の**唯一の情報源** |
| `data/cv.json` | CVの**唯一の情報源** |
| `js/` | 公開ページの描画。コンソールのプレビューも同じものを使う |
| `admin/` | 編集コンソール |
| `image/` | 画像 |
| `tools/` | 移行スクリプトと検査。普段は触らない |
| `plan/` | 設計書・実装計画・この手順書 |
| `index.html` ほか | ページの骨組み。記事本文は入っていない |

**`news.html` と `cv.html` を直接編集しないでください。** 記事の実体は `data/*.json` にあり、HTMLを編集しても表示は変わりません。

## 9. 英語版について

データ構造は英語に対応済みです。すべての項目に「日本語」「English」のタブがあり、英語が未入力の項目は自動的に日本語で表示されます。

英語ページ自体はまだありません。作る場合、必要なのは英語ページの追加だけで、**データ構造と描画の仕組みは変更不要**です。翻訳は必要な項目から少しずつ進められます。

Publications のように言語に依存しない項目は、日本語欄に入れておけば英語版でもそのまま表示されます。
