編集コンソール

ニュースとCVをこの画面から編集し、GitHubへ保存します。 保存の約1〜2分後に公開サイトへ反映されます。

トークンの発行手順（初回のみ）
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token 発行ページを開く →
  2. Repository access → Only select repositories → fumiyasakai.github.io
  3. Permissions → Repository permissions → Contents → Read and write
  4. Expiration → 1年（期限が切れたら再発行が必要です）
  5. 生成された github_pat_… を上の欄に貼ってください

このトークンは、このリポジトリのファイル書き換えだけに使えます。 他のリポジトリやアカウント設定には影響しません。 漏れた場合は GitHub の設定画面から削除すれば即座に無効になります。

記事の書き方、画像の入れ方、間違えたときの戻し方は 運用手順 → にまとめてあります。
